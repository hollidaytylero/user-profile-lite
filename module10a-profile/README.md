# Module 10A – Profile Component with State and Props

## Description

This project demonstrates how to use React props and state to build an interactive profile component. The profile displays an athlete's name, occupation, fun fact, image, biography, and motivational quote.

The name, occupation, and fun fact are passed into the Profile component using props. The useState hook controls whether the additional biography is visible.

## What I Learned

- How to pass props to customize a component
- How to use useState for conditional rendering
- How to design interactive interfaces in React
- How to add click event handlers to buttons
- How to display dynamic content using JSX
- How to import and export React components
