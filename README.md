# Module 9A - Build Your First React Component

## Description

This is a React app created using Vite that renders a UserProfile component. The component includes a name, bio, and image styled with inline CSS.

## What I Learned

* How to set up a React project using Vite
* How to write and structure a functional React component
* How to use JSX and inline styles
* How to render a component in App.jsx
* How to import and export a React component

## Challenges

One challenge I encountered was receiving an error that said the target directory was not empty. This happened because I had already created a folder named `user-profile-lite`. I solved the problem by opening and using the existing project folder instead of trying to create it again.

I also had to learn that React component files, such as `UserProfile.jsx`, should be created inside the `src` folder.
